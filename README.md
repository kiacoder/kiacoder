## What I build

I maintain **[Blackout Kit](https://github.com/kiacoder/blackout-kit)** — an open-source network security & bypass toolkit for Windows and Linux (17+ engines, encrypted vault, self-healing crash recovery, and a privacy-honest safety model). Recent work shipped an enterprise/RBAC layer, a developer SDK + plugin marketplace, and crash-safe VM recovery.
